# Journey Log

Brother Doge Godot began as a layered Godot recreation of Mike's browser game `HODL OR DIE: Brother Doge`.

The port follows the smart path: build a tiny playable layer, expose a smoke-test API, verify the layer, then add the next system.

## v0.1 foundation

Implemented layers:

1. movement / arena / player
2. enemy / weapon / projectile / collision
3. wave timer / XP / level-up upgrade
4. selectable Doge breeds
5. shop between waves
6. boss and telegraphs
7. persistence
8. expanded perk pool + reroll
9. enemy variants + wave director

The current project is still a prototype, but it now has enough systemic gameplay to be a real Godot foundation instead of a throwaway translation.
